✅ Trusted Port

  • DHCP Offer diizinkan lewat port ini
  • Terhubung ke DHCP server resmi
  • Di-set manual: ip dhcp snooping trust
  • Biasanya port uplink ke server room

🚫 Untrusted Port

  • DHCP Offer diblokir dari port ini
  • Port ke end device / client
  • Default semua port: untrusted
  • Rogue DHCP di port ini → langsung diblokir
